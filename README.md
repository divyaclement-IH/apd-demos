# APD demos

Clickable prototypes for care search and Dot, the AI assistant. Open the
published site and pick a demo:

- Billing history
- Care search: providers and facilities
- Dot: find care
- Provider/facility tiering - current (Dot and Traditional)

Providers, facilities, copays and member details are placeholder data.

Keys: → next · ← back · R restart · M switch device. The address bar keeps
your step, device and options, so a shared link opens in the same place.

Plain HTML, CSS and JS with no build step. To run it locally:

```bash
python3 -m http.server 8765
```

Then visit http://localhost:8765/.
